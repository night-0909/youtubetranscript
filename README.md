# youtubetranscript
Download automatic and manual subtitles of Youtube videos

- With youtube-transcript-api module :<br />
transcript.py : download all videos transcript of a Youtube channel<br />
transcript-one.py : download transcript of one video<br />
scrapetube module : I made some changes to fix some issues. See my version : https://github.com/night-0909/scrapetube

- With yt-dlp module :<br />
transcript_yt-dlp.py : download all videos transcript of a Youtube channel
